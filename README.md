# «Зерно 7»: подготовка статического сайта

Этап **до R0**: проектные документы, факты в `js/data.js`, инструменты проверки, favicon и подготовленные изображения. HTML-страницы, CSS и поведение сайта пока не реализованы. Задачи R0–R12 выполняются отдельными запросами; этот результат не заменяет разработку сайта.

## Изображения

По выбору пользователя подготовлен весь набор Gemini: **27 изображений**, 24 WebP и 3 JPEG в `img/`. Исходники `raw/gemini/*.jfif` не изменены. Набор GPT оставлен локально; два разных варианта первого портрета с нестандартными именами не выбраны автоматически.

Проверены декодирование, формат, размеры по каталогу, лимит на каждый файл и сохранность исходников. Три изображения для превью ссылок имеют размер ровно 1200×630. Общий размер набора — 3 034 396 байт (около 2,9 МиБ); самый большой файл — 182 224 байта (около 178 КиБ), меньше лимита ТЗ 300 КиБ. При обработке дополнительные уменьшения ради сжатия не понадобились.

Техническая подготовка завершена, но **приёмка T0.6 не закрыта**: точная версия модели и дата генерации неизвестны; при визуальном просмотре найдены замечания к эмблемам оборудования на `class-01.webp` и высоте питчера (сосуда для молока) на `guide-step-4.webp`. Подробности и соответствие исходников — в [images.md](docs/images.md). Автоматическая ретушь, генерация замен и смешивание наборов не выполнялись.

`raw/`, `out/`, `.venv/`, настройки Obsidian/плагинов и личная тестовая заметка исключены из Git. Они не удалены. Для повторной обработки нужны сохранённые у автора исходники; они не входят в клон репозитория. Не включайте эти локальные папки в ручную загрузку сайта: `.gitignore` управляет Git, а не всеми способами публикации.

## Подготовка изображений

Это вспомогательный инструмент, не сборка сайта. Сам сайт должен остаться чистым HTML/CSS/JS без библиотек и сборки. Обработка проверена на Python 3.14.4 и Pillow 13.0.0.

Команды для Windows PowerShell, **из корня проекта**, не из папки скачанных изображений. Изоляция `-I` не даёт Python импортировать код из каталога исходников. Установите Pillow только в локальную виртуальную среду:

```powershell
python -I -m venv .venv
```

```powershell
.\.venv\Scripts\python.exe -I -m pip install Pillow==13.0.0
```

Для подготовки выбранного набора непосредственно в `img/`:

```powershell
.\.venv\Scripts\python.exe -I -X utf8 tools/prepare_images.py raw/gemini img
```

Для сравнения исходников перед новым выбором используйте отдельный выходной каталог:

```powershell
.\.venv\Scripts\python.exe -I -X utf8 tools/prepare_images.py raw/gemini out/gemini
```

Поддерживаются PNG, JPG, JPEG, JFIF и WebP. Имя без расширения должно совпадать с каталогом в [image-prompts.md](docs/image-prompts.md). Скрипт обрезает изображение по центру, уменьшает и подбирает качество; исходники не меняет. Обычные фотографии не увеличиваются. Для OG маленький исходник отклоняется, а размер результата не уменьшается ниже 1200×630. Неизвестные имена пропускаются с предупреждением; неполный набор, дублирующиеся идентификаторы и повреждённые файлы дают код выхода 1. Результат существующего файла может быть заменён успешной повторной обработкой, поэтому для сравнения пользуйтесь `out/`.

## Проверки

Регрессионные тесты обработки изображений (временные фикстуры создаются вне `img/`):

```powershell
.\.venv\Scripts\python.exe -I -X utf8 tools/test_prepare_images.py
```

Общая проверка сайта использует только стандартную библиотеку Python:

```powershell
python -X utf8 tools/check.py
```

До R0 ожидаемы FAIL по отсутствующим страницам, CSS/JS, документам курса и событиям. Это не означает ошибку обработки изображений; исходники `raw/` и промежуточный `out/` в проверку опубликованного сайта не входят. Lighthouse, адаптивность, форма и события в браузере пока не проверялись: сайта ещё нет.

## Пробелы

- Сайт ещё не реализован: нет девяти HTML-страниц, CSS, скриптов поведения, `files/program-barista.pdf`, PDF гида и `docs/events.md`.
- Нет подтверждённого адреса Vercel и результатов Lighthouse. Боевой сайт и предпросмотры не проверялись.
- Для выбранных изображений автору нужно подтвердить точную версию Gemini, дату генерации, фактические запросы и условия коммерческого использования. Даты файлов не заменяют эти сведения.
- В `class-01.webp` видны эмблемы оборудования; `guide-step-4.webp` неточно показывает высоту питчера. Нужны решение автора и при необходимости исправленные исходники; T0.6 не отмечена полностью выполненной.
- Данные и предположения T0.1 требуют подтверждения автора. `seatsFree` в `js/data.js` — условные числа, не реальная система записи. Дата выдачи ТЗ и календарь T0.7 не подтверждены.
- GA4 ещё не подключён, идентификатор ресурса не задан. Приёмник формы не настроен: `ZERNO.form.endpoint` равен `null`.
- **форма работает в демо-режиме, заявки не отправляются** — это предусмотренный режим при `endpoint = null`; сама форма будет реализована в R6. Сейчас отправлять данные негде, личные данные не сохраняются.

Не получилось: подтвердить происхождение изображений и закрыть визуальные замечания без участия автора; сайт, деплой и Lighthouse не входят в эту подготовительную задачу.
Нейросеть использовалась для: проектной документации, доработки инструментов подготовки и проверки, автоматической обработки предоставленных изображений и описания ограничений; исходный выбранный набор обозначен пользователем как Gemini, точная версия не подтверждена.
