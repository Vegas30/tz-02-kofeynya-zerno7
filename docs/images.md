# Источники изображений

Требование ТЗ: фотографии сгенерированы нейросетью или взяты с бесплатных фотостоков с коммерческой лицензией, источник каждой указан здесь. Проверка `tools/check.py`: каждый файл `.webp`, `.jpg`, `.jpeg` из `img/` должен встречаться в таблице.

## Выбранный набор и состояние проверки

Пользователь выбрал **весь набор Gemini**: 27 исходников `raw/gemini/<id>.jfif`. Подготовка выполнена `tools/prepare_images.py`: обрезка по центру, уменьшение, сжатие, 24 WebP и 3 JPEG в `img/`. Новые сюжеты не генерировались, исходники не изменялись, метаданные исходников в результат не копировались. `img/favicon.svg` сохранён без изменений. GPT не использован; два разных варианта `teacher-0001.png` и `teacher-001.png` в локальном `raw/gpt/` не переименованы и не выбраны автоматически.

**Происхождение:** обозначение Gemini следует из предоставленного набора и выбора пользователя. Точная версия модели, дата генерации, фактически отправленные запросы и коммерческие условия инструмента **не подтверждены**. В таблице приведены соответствующие идентификаторы из каталога промптов, а не восстановленная история генерации. Дата файла не считается датой генерации. Эти сведения должен дополнить автор; выбор Gemini сам по себе не является проверкой лицензии.

**Техническая проверка:** все 27 файлов декодируются; форматы и размеры совпадают с каталогом, три OG — строго 1200×630. Каждый файл меньше 280 КиБ при лимите ТЗ 300 КиБ. Суммарно 3 034 396 байт, самый большой — `class-05.webp`, 182 224 байта. SHA-256 всех 55 исходников, favicon и трёх защищённых файлов не изменились.

**Визуальный просмотр:** просмотрены обзорные листы всех 27 файлов, отдельно увеличены `class-01.webp` и `guide-step-4.webp`. На `class-01.webp` видны светлые эмблемы на кофемолках — требование «без логотипов» нельзя считать выполненным. На `guide-step-4.webp` питчер (сосуд для молока) заметно выше поверхности, тогда как каталог требует держать носик близко к кофе. Это иллюстрация, не точная демонстрация приёма. Ретушь и замены не выполнялись. Полная приёмка T0.6 **не закрыта**: нужны подтверждение происхождения и решение автора по этим изображениям. Слепая оценка GPT и Gemini не проводилась.

## Правила использования

- Формат WebP или JPEG, не больше 300 КБ на файл; для картинок Open Graph размер ровно 1200×630.
- Нейросеть: укажите модель, дату и промпт. Такие изображения подписываются на сайте как «Иллюстрация».
- Сток: название сайта, ссылка на страницу снимка, автор, название лицензии. Лицензия должна разрешать коммерческое использование.
- Фото людей: только если нейросеть сгенерировала несуществующего человека или у снимка модельная лицензия на коммерческое использование. Эти портреты не следует выдавать за подтверждённые фотографии преподавателей.
- Локальные `raw/`, `out/`, `.venv/`, настройки Obsidian и тестовая заметка исключены из Git; в репозиторий входит только готовый набор. Для воспроизведения обработки нужны сохранённые у автора исходники. Исключение из Git само по себе не гарантирует исключения из ручного деплоя: локальные папки не следует публиковать.
