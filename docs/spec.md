# Спецификация сайта «Зерно 7»

ТЗ заказчика: полный текст [tz-full.pdf](tz-full.pdf), сокращённая выжимка [tz.md](tz.md), Приложение А [appendix-a.md](appendix-a.md), сводка требований к сайту [scope-site.md](scope-site.md). Здесь они разложены на проверяемые требования и добавлены решения там, где ТЗ молчит. При расхождении главнее ТЗ.

## 1. Цель и срок

Сайт из 8 страниц и `404.html`, через который идёт набор в декабрьские потоки школы бариста; набор открывается 15 ноября 2026 года. Сейчас делается только этап 1 «Сайт» из шести этапов ТЗ (аналитика, заявки, каналы, отчёты и сдача позже). По ТЗ (раздел 9) сайт нужен к **дню 4** от даты выдачи; поле «Дата выдачи» в вашем экземпляре пустое, поэтому проверьте срок. Календарь — в [workflow.md](workflow.md).

## 2. Где ТЗ неполно и что решено по умолчанию

Это самое важное в документе: каждый пункт нужно либо подтвердить, либо заменить своим решением **до** запуска агентов, иначе четыре модели придумают четыре разных ответа, и сравнение потеряет смысл.

## 4. Страницы и порядок блоков

Источник — [appendix-a.md](appendix-a.md). Порядок блоков обязателен, оформление выбирает исполнитель. Главная кнопка страницы (в схеме выделена) должна быть заметнее остальных: на `index.html` это первый экран и повторный призыв, на `courses.html` — «Выбрать поток», на `beans.html` — кнопка заказа, на `latte-guide.html` — запись на латте-арт, на `contacts.html` — отправка формы.

- **index.html**: шапка (логотип, меню, телефон) → первый экран (оффер «Бариста за 5 занятий», кнопка записи) → курсы (4 карточки со ссылками на `courses.html`) → тест → преподаватели (3 карточки с опытом работы) → фотографии класса (галерея из 6–8 фото) → повторный призыв к записи → подвал (адрес, соцсети, политика).
- **courses.html**: 4 карточки курсов (программа по занятиям, цена) → даты потоков (кнопка «Выбрать поток») → программа курса PDF (`files/program-barista.pdf`) → частые вопросы (5 вопросов).
- **menu.html**: фильтр (кофе, чай, десерты, без лактозы) → позиции меню (не менее 20, с ценами) → карта и адрес.
- **beans.html**: карточки 6 сортов (страна, обработка, вкус) → как выбрать обжарку (светлая, средняя, тёмная) → кнопка заказа, ведёт на `contacts.html`.
- **latte-guide.html**: гид «Сердце на капучино за 5 шагов» (5 шагов с фото) → скачать гид PDF → промокод LATTE10 (кнопка «Скопировать») → кнопка записи на латте-арт. На страницу ведёт ссылка из автоответа Instagram, значит, она должна быть понятна без остального сайта.
- **contacts.html**: форма заявки (`name`, `phone`, `email`, `course`, `start_month` и согласие, ТЗ 6.3) → телефон и e-mail → кнопки Telegram и WhatsApp.
- **thanks.html**: номер заявки (`request_id` из формы) → что будет дальше («звонок в течение часа») → ссылки на соцсети.
- **privacy.html**: текст политики: оператор (реквизиты из шапки ТЗ), цели, состав данных, сроки; плюс права человека и отзыв согласия (152-ФЗ).
- **404.html**: понятное сообщение и ссылка на главную. Vercel отдаёт этот файл сам.

## 5. Фирменный стиль

Цвета: кофейный `#7A4A2A`, сливочный `#F6EFE6`, графит `#24211F`. Шрифты Google Fonts: Unbounded для заголовков, Inter для текста.

Контраст по WCAG посчитан, он нужен для Accessibility ≥ 90:

| Сочетание | Контраст | Можно для текста |
|---|---|---|
| графит на сливочном | 14,0 | да |
| кофейный на сливочном | 6,5 | да |
| белый на кофейном | 7,4 | да (кнопки) |
| **кофейный на графитовом** | **2,2** | **нет**: на тёмном фоне текст делайте сливочным |

Шрифты: Unbounded широкий, на 375 px длинные заголовки уезжают за край. Размер заголовков через `clamp()`, длинные слова переносятся. Подключать только нужные начертания (Inter 400 и 600, Unbounded 600 и 700), `display=swap`, иначе страдает Performance.
