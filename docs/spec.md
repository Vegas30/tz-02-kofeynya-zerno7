# Спецификация сайта «Зерно 7»

ТЗ заказчика — [tz.md](tz.md). Здесь оно разложено на проверяемые требования и добавлены решения там, где ТЗ молчит. При расхождении главнее ТЗ.

## 1. Цель и срок

Сайт из 8 страниц и `404.html`, через который идёт набор в декабрьские потоки школы бариста. Набор открывается 15 ноября 2026 года, а сегодня 8 ноября: на всё 7 дней. Календарь работ — в [workflow.md](workflow.md).

## 2. Где ТЗ неполно и что решено по умолчанию

Это самое важное в документе: каждый пункт нужно либо подтвердить, либо заменить своим решением **до** запуска агентов, иначе четыре модели придумают четыре разных ответа и сравнение потеряет смысл.

| № | Что неясно | Решение по умолчанию |
|---|---|---|
| D1 | В файле ТЗ нет Приложения А (схемы страниц), хотя на него есть ссылка | Порядок блоков берём из столбца «Обязательные блоки» таблицы 3.2. Если Приложение А у вас есть, положите его в `docs/` и оно главнее |
| D2 | У сайта нет сервера, а форма должна «принять заявку» и выдать «Номер заявки» | Клиентская имитация: проверка полей → номер заявки на клиенте → переход на `thanks.html?id=…`. Заявка **никуда не уходит**, личные данные нигде не хранятся. В README это написано прямо. Подключение Formspree и подобных сервисов в ТЗ не требуется |
| D3 | Нет контактов, соцсетей, адреса, преподавателей, сортов зерна, чая и пометок «без лактозы» | Заполнить `js/data.js` (задача T0.1). Правило ТЗ запрещает публиковать то, чего нет в сведениях, поэтому агентам нельзя придумывать их самим |
| D4 | События (`cta_click` и др.) названы, но не сказано, куда их слать | Единая функция `Z7.track(name, params)` кладёт событие в `window.dataLayer`. Счётчики Метрики и GA не подключаем: ID нет, они бьют по Lighthouse и требуют отдельного согласия |
| D5 | Число свободных мест нужно показывать, а источника нет | Демо-числа в `js/data.js`. Один поток намеренно с нулём мест, чтобы был виден неактивный вариант. В README пишем «данные о местах демонстрационные» |
| D6 | Промокод `LATTE10`, размер скидки не указан | Показываем только код, скидку не называем. В форме есть необязательное поле «Промокод» |
| D7 | «Термин пояснять при первом упоминании» — на сайте или на странице? | На каждой странице при первом упоминании на ней (человек может зайти с любой страницы). Пояснение — короткая фраза в скобках, не всплывающая подсказка: на телефоне её не видно |
| D8 | «Альтернатива — каждую субботу», а в расписании нужны конкретные даты | Показываем субботы декабря 2026: 5, 12, 19, 26 декабря, плюс подпись «и далее каждую субботу» |
| D9 | У корпоративного мастер-класса нет потоков | В блоке дат вместо потоков кнопка «Обсудить дату» → форма с выбранным курсом. Дат и условий не придумываем |
| D10 | Политика конфиденциальности требует данных оператора, а реквизитов нет | Оператор назван «Зерно 7», без ИНН и адреса. В README: для настоящего запуска нужны реквизиты и проверка юристом. Это учебный документ, не юридическая консультация |
| D11 | «Программа курса PDF» без тем занятий | В PDF только факты из ТЗ: название, число занятий, длительность, цена, размер группы. Темы занятий не выдумываем. «Гид по латте-арту» — общая техника рисунка, не факты о компании |
| D12 | Фото класса сгенерированы нейросетью, а класс реальный | Подпись «Иллюстрация» рядом с такими фото, чтобы не вводить людей в заблуждение |
| D13 | «Кнопка заказа» зерна: куда ведёт | На блок мессенджеров `contacts.html#messengers`. Магазина и корзины нет |

## 3. Требования

«Проверка»: `check` — автоматически скриптом `tools/check.py`, `LH` — Lighthouse, `вручную` — по чек-листу из [workflow.md](workflow.md).

| ID | Требование (источник — ТЗ) | Проверка |
|---|---|---|
| G-01 | Статический HTML/CSS/JS, открывается без сборки. Без `type="module"` и `fetch` локальных файлов (иначе не откроется двойным кликом) | check |
| G-02 | Интерфейс на русском. Нет «Lorem ipsum», «Заголовок», «Ваш текст» | check |
| G-03 | 8 страниц и `404.html`, единые шапка и подвал, в меню выделена текущая страница (`aria-current="page"`) | check |
| G-04 | Ширина 375, 768, 1280 px: нет горизонтальной прокрутки, цели нажатия не меньше 44×44 px | вручную |
| G-05 | У каждой страницы свои `title`, `description`, `og:title`, `og:description`, `og:image` (1200×630), favicon | check |
| G-06 | Изображения WebP или JPEG, каждое не больше 300 КБ, у каждого непустой `alt` | check |
| G-07 | Lighthouse главной (мобильный режим): Performance ≥ 70, Accessibility ≥ 90, SEO ≥ 90 | LH |
| G-08 | Форма: флажок согласия со ссылкой на `privacy.html`, по умолчанию не отмечен, без него отправка невозможна | check + вручную |
| G-09 | Тест на главной: 4 вопроса → один из 4 курсов и кнопка записи. Правила — [quiz.md](quiz.md) | вручную |
| G-10 | На `courses.html` у каждого потока число мест из массива JS; потока без мест неактивен, кнопка не работает | вручную |
| G-11 | Фото — нейросеть или сток с коммерческой лицензией; источник каждого в [images.md](images.md) | check |
| G-12 | Репозиторий `tz-02-kofeynya-zerno7` публичный, Vercel обновляется после push в `main`, адрес в README | check + вручную |
| G-13 | Тексты только по сведениям ТЗ; цены только из списка; тон на «вы»; термины поясняются | check (цены) + вручную |
| G-14 | События из таблицы 3.2 отправляются; каталог — [data-schema.md](data-schema.md) | check (наличие в коде) + вручную |
| G-15 | Требование курса: журнал запросов к нейросети `docs/prompts.md` | check |

## 4. Страницы и порядок блоков

Порядок блоков обязателен (ТЗ 3.2), оформление выбирает исполнитель.

- **index.html**: шапка и меню → первый экран → курсы → тест → преподаватели → фотографии класса → повторный призыв к записи → подвал.
- **courses.html**: карточки 4 курсов → даты потоков → программа курса PDF → частые вопросы.
- **menu.html**: фильтр (кофе, чай, десерты, без лактозы) → позиции → карта и адрес.
- **beans.html**: карточки сортов → как выбрать обжарку → кнопка заказа.
- **latte-guide.html**: гид «Сердце на капучино за 5 шагов» → скачать PDF → промокод LATTE10 → кнопка записи на латте-арт. На страницу ведёт ссылка из автоответа Instagram, значит, она должна быть понятна без остального сайта.
- **contacts.html**: форма заявки → телефон и e-mail → кнопки Telegram и WhatsApp (с якорем `#messengers`).
- **thanks.html**: номер заявки → что будет дальше → ссылки на соцсети.
- **privacy.html**: текст политики (152-ФЗ): кто оператор, какие данные (имя, телефон, e-mail, комментарий), цель, срок, права человека, как отозвать согласие.
- **404.html**: понятное сообщение и ссылка на главную. Vercel отдаёт этот файл сам.

## 5. Фирменный стиль

Цвета: кофейный `#7A4A2A`, сливочный `#F6EFE6`, графит `#24211F`. Шрифты Google Fonts: Unbounded для заголовков, Inter для текста.

Контраст по WCAG посчитан, он нужен для Accessibility ≥ 90:

| Сочетание | Контраст | Можно для текста |
|---|---|---|
| графит на сливочном | 14,0 | да |
| кофейный на сливочном | 6,5 | да |
| белый на кофейном | 7,4 | да (кнопки) |
| **кофейный на графитовом** | **2,2** | **нет**: на тёмном фоне текст делайте сливочным |

Шрифты: Unbounded широкий, на 375 px длинные заголовки уезжают за край. Размер заголовков через `clamp()`, длинные слова переносятся. Подключать только нужные начертания (Inter 400 и 600, Unbounded 600 и 700), `display=swap`, иначе страдает Performance.
