# Разбивка на задачи

Размер: S до часа, M 1–3 часа, L больше. «Готово, когда» всегда проверяемо. G-xx — требования из [spec.md](spec.md), S-xx — из [scope-site.md](scope-site.md). Состав и порядок блоков страниц — [appendix-a.md](appendix-a.md).

**Как задачи превращаются в запросы к нейросети.** ТЗ (3.1) требует в журнале минимум запрос на структуру, отдельный запрос на каждую страницу и запросы на исправления. Поэтому исполнитель получает не весь список сразу, а последовательность запросов, один запрос на один пункт колонки «Запрос». Один запрос это один коммит. Тексты запросов — в [workflow.md](workflow.md), раздел 4.
