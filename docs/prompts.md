# Журнал запросов к нейросети

Требование задания: все запросы сохраняются в порядке отправки; для каждого указаны номер, текст запроса, что получилось, что пришлось исправить вручную.

Правила ведения: запись добавляется сразу после запроса, номера растут без пропусков, старые записи не меняются (кроме опечаток), текст запроса приводится как отправлен. Если вручную ничего не правили, так и пишем: «Вручную не изменялось».

Как нам всё это организовать?

**Что получилось:** способы передать ТЗ из Obsidian (файл, текст, репозиторий), структура vault внутри `docs/`, формат этого журнала.

**Что исправлено вручную:** заполняется автором после проверки.
